# iパスメモラ

Memora X の学習体験（スワイプ仕分け・苦手リスト・徹底再出題）を参考にした、ITパスポート頻出用語の iPhone 向け学習アプリです。

App Store のネイティブアプリではなく、**ホーム画面に追加できる Web アプリ（PWA）** です。Safari から追加すると、全画面の専用アプリのように使えます。データは端末内の localStorage のみ。

## iPhone への入れ方

1. iPhone の Safari で `index.html` を開く
2. 共有ボタン（□↑）をタップ
3. 「ホーム画面に追加」
4. 追加されたアイコンから起動

オフラインでも、一度開けばキャッシュから動作します。

## 操作

- カードをタップ → 意味を表示
- 右スワイプ / 「覚えた」→ 定着
- 左スワイプ / 「苦手」→ 苦手リストへ
- 2回連続で「覚えた」と学習中扱いになり、さらに続くと「覚えた」へ
- 徹底暗記モードでは、間違えた語が数問後に再出題されます
- まぎらわしい用語はワンタップで比較できます

収録はシラバス 6.3〜6.5 周辺の頻出・混同しやすい語を中心にした約 100 語です。過去問そのものの著作物は含めていません。
