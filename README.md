# iパスメモラ

Memora X の学習体験（スワイプ仕分け・苦手リスト・徹底再出題）を参考にした、ITパスポート頻出用語の iPhone 向け学習アプリです。

App Store のネイティブアプリではなく、**ホーム画面に追加できる Web アプリ（PWA）** です。Safari から追加すると、全画面の専用アプリのように使えます。データは端末内の localStorage のみ。

## iPhone への入れ方

1. GitHub Pages の URL を Safari で開く
2. 共有ボタン（□↑）をタップ
3. 「ホーム画面に追加」
4. 追加されたアイコンから起動

## 操作

- カードをタップ → 意味を表示
- 右スワイプ / 「覚えた」→ 定着
- 左スワイプ / 「苦手」→ 苦手リストへ
- 徹底暗記モードでは、間違えた語が数問後に再出題
- **四肢択一**：用語を見て正しい説明を4つから選ぶ。不正解は苦手リストへ

収録はシラバス 6.3〜6.5 周辺の頻出・混同しやすい語を中心にした約 390 語です。過去問本文は含めていません。
